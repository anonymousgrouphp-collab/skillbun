# Cross-Platform Packaging and Distribution: Study Guide

Packaging packages compile raw source scripts and binaries into standard formats ready to be installed on customer OS environments.

## 1. Key Concepts

### Concept 1: Wix Toolset & NSIS
Using advanced installer scripting frameworks to build customizable Windows installation flows (MSI/EXE).

### Concept 2: macOS DMG creation
Creating standard DMG drag-to-Applications folder packages, configuring background graphics.

### Concept 3: Linux Packaging Standards
Building portable AppImage files, snap packages, or native deb packages for distribution across Linux distros.
