# User Acceptance Testing (UAT): Study Guide

UAT gathers feedback from actual users testing preview/beta builds under real conditions to identify user experience gaps and platform bugs.

## 1. Key Concepts

### Concept 1: Beta Release channels
Releasing preview builds to early testers using dedicated channels (e.g., TestFlight, beta updates).

### Concept 2: In-App Feedback tools
Providing simple mechanisms for users to capture screenshots and submit reports directly from the app interface.

### Concept 3: UAT Metrics collection
Analyzing app metrics and feedback comments to prioritize bug fixes and feature adjustments before production release.
