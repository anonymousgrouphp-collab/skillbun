# Capstone Project: End-to-End Desktop Application: Study Guide

The capstone project requires building, signing, packaging, and publishing a cross-platform desktop application from scratch.

## 1. Key Concepts

### Concept 1: Complex Native App Idea
Building an application that utilizes local file systems, native menus, offline database persistence, and external APIs.

### Concept 2: Full Packaging Pipeline
Configuring packaging script setups to generate signed installer binaries for both Windows and macOS.

### Concept 3: Auto-Update Server deploy
Deploying a remote update channel server and verifying that the compiled client automatically downloads updates.
