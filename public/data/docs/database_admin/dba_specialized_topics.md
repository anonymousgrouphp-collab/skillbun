# Specialized & Emerging Database Technologies: Study Guide

Beyond relational databases, modern DBAs must manage specialized data stores tailored for specific workloads like search, graph models, real-time metrics, and global scale.

## 1. Key Concepts

### Concept 1: NoSQL Architectures
Key-value, document, wide-column, and graph databases, optimized for horizontal scaling and flexible schemas.

### Concept 2: Search & Analytical Engines
Databases specialized in full-text indexing, vector search, or aggregation-heavy workloads (e.g., Elasticsearch, ClickHouse).

### Concept 3: Distributed SQL
Databases that offer global scalability and partition tolerance while maintaining ACID guarantees (e.g., CockroachDB, Spanner).
