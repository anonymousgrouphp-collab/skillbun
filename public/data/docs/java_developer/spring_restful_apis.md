# Building RESTful APIs with Spring Boot

> Part of the **Java Developer** roadmap on SkillBun | Difficulty: **Essential**

Understand HTTP methods (GET, POST, PUT, DELETE, PATCH), request/response handling using `@RequestBody`, `@ResponseBody`, `ResponseEntity`, path variables, and request parameters. Learn to structure APIs with Data Transfer Objects (DTOs).
