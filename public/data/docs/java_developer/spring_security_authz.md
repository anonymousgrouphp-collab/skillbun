# Spring Security & Authorization

> Part of the **Java Developer** roadmap on SkillBun | Difficulty: **Advanced**

Implement robust security in your Spring Boot applications. Differentiate between authentication and authorization. Learn to secure endpoints with Basic Auth, Form Login, JWT (JSON Web Tokens), and explore basics of OAuth2 (Resource Server, Client).
