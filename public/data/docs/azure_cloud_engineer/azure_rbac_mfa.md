# Role-Based Access Control (RBAC) & Multi-Factor Authentication (MFA)

Welcome to a crucial topic for any Azure Cloud Engineer: implementing robust security through Role-Based Access Control (RBAC) and Multi-Factor Authentication (MFA). These two pillars are fundamental to achieving the principle of least privilege and significantly enhancing the security posture of your Azure environment.

## 1. Azure Role-Based Access Control (RBAC)

Azure RBAC provides fine-grained access management for Azure resources. It allows you to manage who has access to Azure resources, what they can do with those resources, and what areas they can access.
