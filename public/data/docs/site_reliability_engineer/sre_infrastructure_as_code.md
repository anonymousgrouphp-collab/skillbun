# Infrastructure as Code (IaC)

> Part of the **Site Reliability Engineer** roadmap on SkillBun | Difficulty: **Essential**

Learn to define and manage infrastructure declaratively using Infrastructure as Code (IaC) tools like Terraform or Pulumi. Understand state management, modularization, secrets integration, and applying IaC within CI/CD pipelines for reproducible and scalable infrastructure.
