# Modern C++ Language & STL: A Comprehensive Study Guide

Modern C++ empowers developers to write efficient, robust, and maintainable code using contemporary features and best practices. This guide covers the essential aspects of Modern C++ (C++11/14/17/20) and the Standard Template Library (STL).

## 1. Object-Oriented Programming (OOP) Fundamentals in C++

C++ is a multi-paradigm language, with strong support for OOP principles:

*   **Classes & Objects**: Define custom data types (classes) that encapsulate data (member variables) and behavior (member functions). Objects are instances of classes.
*   **Encapsulation**: Bundling data and methods that operate on the data within a single unit (class), and restricting direct access to some of the object's components (using `public`, `private`, `protected` access specifiers).
