# Content-Based Recommendation

> Part of the **Recommendation Systems Engineer** roadmap on SkillBun | Difficulty: **Essential**

Explore how to recommend items based on item attributes and user profiles. Learn techniques for creating item feature vectors (e.g., TF-IDF, word embeddings), user profiling (e.g., averaged item features, explicit preferences), and using similarity measures (e.g., cosine similarity) to match users to items they might like based on their past interactions.
